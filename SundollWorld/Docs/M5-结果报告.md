# M5 结果报告：主控台整合第一批

日期：2026-08-25
状态：**M5 核心状态与命令切片已实现；完整主持 UI 仍为 Partial**

## 本批完成

- 在权威 `M1WorldState` 中增加可迁移的 M5 主控台状态，不把主持状态塞进 Unity Transform。
- 支持多个地图槽位：创建、切换、重命名；切换前自动把当前地图内容写回槽位，切换后恢复目标地图草稿/发布内容。
- 增加按地图保存的迷雾格、动态标注和交互对象状态。
- M5 命令接入现有 Command Bus、Undo/Redo、Command Envelope、Journal 和 Canonical Hash。
- Workbench 顶栏/左栏已增加主持地图创建与切换入口、地图槽列表、迷雾格隐藏/揭示、动态标注保存/删除和交互对象开/关入口；Inspector/History 继续沿用 M3 的固定布局。

## 验证证据

- EditMode：`TestResults_EditMode_20260825_m5m6m7_ui.xml`，76/76 通过。
- PlayMode：`TestResults_PlayMode_20260825_m5m6m7_ui.xml`，4/4 通过，包含新增主持控件存在性检查。
- 覆盖地图切换不丢内容、迷雾/标注/交互状态、命令 Undo/Redo 和 JSON/Envelope 兼容。

## 未关闭

- 迷雾刷、动态标注拖动、Hierarchy、通用右键交互菜单和完整多地图主持流程还未做成正式高级 UI；当前已提供基础操作入口。
- 多地图真实窗口操作与长时间主持性能尚未验证。
- M5 数据随 M2/M4 开发存档仍属于 pre-v1，M7 冻结前不承诺长期兼容。
