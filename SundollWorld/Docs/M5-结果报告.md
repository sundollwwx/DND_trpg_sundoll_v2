# M5 结果报告：主控台整合第一批

日期：2026-08-25
状态：**M5 主控台基础 UI 已实现；长时间主持与高级主持流程仍为 Partial**

## 本批完成

- 在权威 `M1WorldState` 中增加可迁移的 M5 主控台状态，不把主持状态塞进 Unity Transform。
- 支持多个地图槽位：创建、切换、重命名；切换前自动把当前地图内容写回槽位，切换后恢复目标地图草稿/发布内容。
- 增加按地图保存的迷雾格、动态标注和交互对象状态。
- M5 命令接入现有 Command Bus、Undo/Redo、Command Envelope、Journal 和 Canonical Hash。
- Workbench 顶栏/左栏已增加主持地图创建与切换入口、地图槽列表、迷雾格隐藏/揭示、动态标注保存/删除和交互对象开/关入口；Inspector/History 继续沿用 M3 的固定布局。
- 新增 M5 运行时投影：隐藏迷雾显示遮罩，动态标注显示为可重建的地图视图；缺失 View 后可从纯数据重建。
- 增加 Hierarchy 面板，按地图对象、棋子实例、当前地图动态标注分组，并可回填 Inspector/选区。
- 增加地图通用右键菜单：拾取、门/箱子新增、对象打开/关闭/切换/旋转/删除、当前格迷雾切换和动态标注创建；所有操作仍走现有 Facade/Command Bus。
- 增加当前地图重命名入口和“地图编辑 / 主持预览”模式提示，形成主持操作的连续入口。

## 验证证据

- 最新 PlayMode：`TestResults_PlayMode_20260825_m5_hierarchy_context.xml`，5/5 通过，真实加载 Workbench 并检查 Hierarchy、右键菜单、地图对象菜单项和重建清理。
- 既有 M5 投影复跑：`TestResults_PlayMode_20260825_m5m6m7_projection.xml`，5/5 通过，包含迷雾遮罩/动态标注创建与销毁重建。
- 覆盖地图切换不丢内容、迷雾/标注/交互状态、命令 Undo/Redo 和 JSON/Envelope 兼容。

## 未关闭

- 迷雾刷、动态标注拖动和批量主持操作仍未做成高级工具；当前右键菜单提供单格原子操作。
- 多地图真实窗口操作、玩家视图分离和长时间主持性能尚未验证。
- M5 数据随 M2/M4 开发存档仍属于 pre-v1，M7 冻结前不承诺长期兼容。
