# M3 结果报告

日期：2026-08-25  
状态：M3 功能范围已实现；自动化验证通过，性能、正式 macOS IL2CPP 和 Windows 发布矩阵仍未关闭。

## 已完成

- 正式 `M3Workbench.unity`：正交 Camera、UI Toolkit 固定布局、顶部项目/保存状态、左侧工具与五个内容层、中央地图、右侧 Inspector、底部历史状态。
- 五个内容层分别投影到 Tilemap：`terrain`、`wall`、`object`、`interaction`、`static-annotation`；Map Object 另有可见的对象投影层。
- Input System 接入画笔、橡皮擦、直线、矩形、填充、Esc 取消、光标中心滚轮缩放、中键平移和 Cmd/Ctrl+Z/Y/C/X/V/R。
- 选择、复制、剪切、粘贴和顺时针 90° 旋转；剪贴板以选区左下角归一化，粘贴越界或目标锁定时整批拒绝。
- 五层显隐、锁定、排序、当前工具/图层、缩放和平移写入 Workspace State format 2；选择和剪贴板不持久化。
- `M3MapObjectCommand` 支持稳定 ID 的门与箱子，保存坐标、四向旋转、open/closed 状态，以及 `Open/Close/Toggle/Rotate` 动作；发布时深拷贝对象。
- World Schema 默认升级为 2；Schema 1 读取保留旧字段并补齐新对象列表默认值。M3 使用新的 `SundollWorld_M3` 本机开发项目根目录，旧开发存档不改写。
- 地图编辑继续经过 `M3MapEditorFacade`、Command Bus、`WorldChangeSet` 和 M2 Journal；Tilemap 只做投影，脏区刷新使用 `LastDirtyBounds`。

## 未关闭项

- M7 已在 macOS 形成普通批量编辑 p95 `<50 ms`、Snapshot 主线程 p95 `<16 ms`、后台保存 p95 `<2 s`、10,000 Journal Batch `<5 s` 的正式基线；2560×1440 稳定 60 FPS/分配预算仍未测。
- 当前环境没有 Windows，因此 Windows IL2CPP、Windows 原子写盘、跨平台互开、双平台强制退出和 Windows Smoke 保持发布阻塞。
- PlayMode 使用无图形批处理验证了生命周期和状态投影；真实窗口中的视觉布局、滚轮和中键手感仍需在可操作的桌面 Unity 窗口中复验。
- Unity Licensing Client 在离线批处理日志中仍可能报告 access token 更新失败/网络配置超时；本轮授权本机可完成编译和测试，这些是环境级提示，不归因于 M3 代码。

## 结论

M3 的功能范围可以交给后续 M4 使用，状态为 **Ready with limitations**。进入发布候选前，必须补做性能采样、真实桌面视觉/输入复验、macOS universal IL2CPP 重建，并在 Windows 可用后完成 Windows/跨平台存档矩阵。
