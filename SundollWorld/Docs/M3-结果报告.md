# M3 结果报告

日期：2026-08-25  
范围：地图制作器 MVP 最小切片  
状态：M3 地图制作器 MVP 已完成连续笔画、视口、几何工具和正式多内容图层模型切片验证，完整 M3 退出条件尚未关闭。

## 本轮实现

- `M3PaintCellsCommand`：批量绘制/擦除格子，先完整校验坐标和内容，再修改状态；一批操作只增加一次 World Revision，可由 Command Bus 一次 Undo/Redo。
- `M3PaintCellsCommand`：批量应用改用 `(x, y, layerId)` 索引，避免中等地图逐格线性查找造成 O(n²) 退化，并允许同坐标多图层共存。
- 正式内容图层：加入稳定的 `terrain`、`wall`、`object`、`interaction`、`static-annotation` 图层 ID；旧 `contentId` 仍可自动推断图层。
- 兼容与持久化：`M1MapCell`、DeepClone、M1 旧绘制命令、发布版本、M2 Canonical Hash 和 JSON 保存链路均保留图层；没有显式图层的旧状态继续使用兼容哈希格式。
- `M3MapEditorFacade`：把地图编辑意图接入现有 `M1CommandBus`，不直接修改 Scene、Tilemap 或 GameObject。
- `M3GridStrokeRasterizer`：纯 C# Bresenham 直线栅格化，包含起点和终点，相邻格子不会产生空洞。
- `M3GridShapeRasterizer`：提供矩形框、实心矩形和四连通区域填充；填充使用目标内容相等判断和边界访问标记。
- `M3RuntimeMapEditor`：运行时诊断面板，显示当前 `MapDocument` 草稿，提供五个内容图层、按当前图层擦除/填充、Undo、Redo、发布 `MapContentVersion`，以及可缩放/平移的固定地图视口。
- 连续笔画与几何工具：左键按下、拖动过程中累积去重格子，松开时只调用一次 `PaintCells`；直线、矩形框、实心矩形和填充也复用同一原子批量命令。
- 视口交互：滚轮按光标位置缩放（12–72 px/格），中键平移，工具栏支持视口复位。
- `M3GridViewport`：提供地图边界、脏区合并/清空、可见格子边界计算；运行时绘制只遍历当前视口内的格子，避免按整张地图逐格绘制。
- Dirty Region 接入：批量绘制/擦除记录受影响的包围盒，Undo/Redo 将整张地图标记为需要重新检查；运行时面板显示可见格子数和最近脏区。
- `M3ContentLookupCache`：运行时按地图对象和 Revision 缓存 `(x, y, layerId)` 内容索引；接受的绘制/擦除批次只更新脏区中的键，地图替换、Undo/Redo 或 Revision 不连续时安全回退为完整重建。
- `M3LayerEditState`：为五个正式内容图层提供本机工作区级的显示/隐藏和锁定/解锁状态；隐藏层不参与当前视图选层，锁定层阻止画笔、几何工具和填充提交。
- `M3WorkspaceStateStore`：将当前地图的隐藏/锁定图层状态以版本化 `workspace-state.json` 侧车文件原子写入 M2 Project Root；Workspace 状态不进入 `MapDocument`、World Revision、Canonical Hash 或 `.sundollpkg`，缺失、损坏、版本不匹配和地图 ID 不匹配时回退默认状态。
- M2 接入：每次接受的地图命令写入 Journal，手动保存和重新加载仍由 `M2SaveSession` 负责。
- 所有新增 Unity 资产脚本均由 Unity 自动生成对应 `.meta` 文件；没有新增包、场景序列化或 Project Settings 修改。

## 验证结果

- EditMode：最新全量共 38 个测试，38 通过、0 失败、0 忽略；包含 256×256 批量绘制/保存/重载基准、直线、矩形、填充、Dirty Region、局部内容缓存、可见区域边界、图层编辑状态和 Workspace State 容错/往返测试。
- M3 测试覆盖：批量绘制原子性、Undo/Redo、擦除、发布内容版本、M2 保存重载后的草稿恢复，以及同坐标多层共存、指定图层擦除、多层哈希重载和发布保留。
- 连续笔画测试覆盖：斜线栅格化起终点、相邻格无空洞、批量绘制一次 Revision、一次 Undo 整体撤销。
- 几何工具测试覆盖：矩形框/实心矩形数量和中心格、填充遇到不同内容时停止扩散。
- Unity Editor：刷新 AssetDatabase 后相关程序集重新编译；最新批处理 XML 为 38/38 EditMode 通过，0 失败、0 忽略。
- Play Mode：缓存改动后再次进入并退出 `M1Bootstrap`，M3 运行时 8×8 网格面板正常显示；之前已确认隐藏/锁定 Terrain 的 `workspace-state.json` 恢复、隐藏层不绘制、锁定点击不产生 Journal。人工 Computer Use 已确认画笔、直线、矩形框、实心矩形和填充均能生成预期 Wall 符号，并通过 Undo 清理；滚轮/中键人工输入因当前接口无法定向滚轮和中键拖拽，仍未宣称通过。

## 当前边界

- 这是最小切片，不是完整地图制作器：尚未加入真正的 2D Camera 视口、框选、多选、复制粘贴或性能 Chunk；当前视口仍是 IMGUI 诊断视口。
- Dirty Region 当前已完成受影响范围跟踪和局部内容索引更新；由于视口仍是 IMGUI，当前仍会按可见范围提交 GUI 绘制，尚未实现 Texture/Tilemap 层面的局部像素重绘。Workspace State 当前只持久化图层显示/锁定，不包含选中图层、工具、缩放和平移；正式多内容层数据模型仍没有图层排序配置、拾取、框选、多选、复制粘贴和旋转。
- Bootstrap 场景仍没有 Camera，当前网格面板是 IMGUI 诊断界面，不是最终 Workbench UI。
- M2 的 Windows、跨平台互开和强制退出恢复矩阵仍因没有 Windows 环境而未完成。

下一步应把 IMGUI 诊断视口替换为真正的 2D Workbench/渲染投影，并补性能 Chunk/门槛；滚轮/中键需要在真实鼠标环境复验，M2 跨平台验证仍是发布前必要条件。
