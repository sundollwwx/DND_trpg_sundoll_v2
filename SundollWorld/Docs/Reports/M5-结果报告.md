# M5 结果报告：主控台整合第一批

日期：2026-08-30
状态：**M5 核心主持工作流已完成；真实窗口手感与长时间主持验证仍为 Partial**

## 本批完成

- 在权威 `M1WorldState` 中增加可迁移的 M5 主控台状态，不把主持状态塞进 Unity Transform。
- 支持多个地图槽位：创建、切换、重命名；切换前自动把当前地图内容写回槽位，切换后恢复目标地图草稿/发布内容。
- 增加按地图保存的迷雾格、动态标注和交互对象状态。
- M5 命令接入现有 Command Bus、Undo/Redo、Command Envelope、Journal 和 Canonical Hash。
- Workbench 顶栏/左栏已增加主持地图创建与切换入口、地图槽列表、迷雾格隐藏/揭示、动态标注保存/删除和交互对象开/关入口；Inspector/History 继续沿用 M3 的固定布局。
- 新增 M5 运行时投影：隐藏迷雾显示遮罩，动态标注显示为可重建的地图视图；缺失 View 后可从纯数据重建。
- 增加 Hierarchy 面板，按地图对象、棋子实例、当前地图动态标注分组，并可回填 Inspector/选区。
- 增加地图通用右键菜单：拾取、门/箱子新增、对象打开/关闭/切换/旋转/删除、当前格迷雾切换和动态标注创建；所有操作仍走现有 Facade/Command Bus。
- 增加当前地图重命名入口和“地图编辑 / 主持预览”模式提示，形成主持操作的连续入口。

## 验证证据

- 最新 EditMode：`TestResults_EditMode_20260825_m5_hierarchy_context.xml`，78/78 通过，新增地图对象上下文操作的添加、切换、旋转、删除和 Undo 检查；同一套全量证据还包含 M7 性能基线。
- 最新 PlayMode：`TestResults_PlayMode_20260825_m5_hierarchy_context.xml`，6/6 通过，真实加载 Workbench 并检查 Hierarchy、右键菜单、地图对象菜单项和重建清理；同一套证据新增 M4 64 棋子纹理基线。
- 既有 M5 投影复跑：`TestResults_PlayMode_20260825_m5m6m7_projection.xml`，5/5 通过，包含迷雾遮罩/动态标注创建与销毁重建。
- 覆盖地图切换不丢内容、迷雾/标注/交互状态、命令 Undo/Redo 和 JSON/Envelope 兼容。

## 未关闭

- 迷雾刷、动态标注拖动和批量主持操作仍未做成高级工具；当前右键菜单提供单格原子操作。
- 多地图真实窗口操作、玩家视图分离和长时间主持性能尚未验证。
- M5 数据随 M2/M4 开发存档仍属于 pre-v1，M7 冻结前不承诺长期兼容。

## 2026-08-27 增量更新：主持操作工作流

- 增加可调半径的迷雾揭示/隐藏笔刷；一整次拖动以单个 `M5.SetFogBatch` 命令提交，支持整笔 Undo/Redo、Envelope 编解码和保存队列。
- 增加动态标注拖动工具；移动沿用 `M5.UpsertAnnotation`，不会丢失文本、颜色或显隐状态。
- “主持预览”升级为真正的玩家预览：通过 M6 Audience Projection 生成过滤后的视图，移除未揭示地图内容和隐藏棋子，隐藏主持动态标注，并把地图编辑入口置为只读。
- 最新验证为 EditMode `84/84`、PlayMode `12/12`；证据见 `Docs/Evidence/M5-usability-slice-20260827.md`。

本次仍未关闭真实窗口输入手感、迷雾/标注长时间主持性能和 Windows/跨平台矩阵。

## 2026-08-30 增量更新：多地图工作区恢复

- 修复了工作区状态只使用一个 `workspace-state.json` 的覆盖问题。现在每张地图按稳定 Map ID 哈希保存各自的工作区文件，地图 ID 本身不会被当成文件路径，因此跨平台与特殊字符均不会造成路径冲突。
- 旧单文件状态继续在读取时兼容；用户下一次保存对应地图时会自然写入新位置，旧开发存档和样本不会被删除或改写。
- 切换主持地图会先持久化当前地图的工作区并将草稿加入既有异步保存队列，再执行已 Journal 化的切图命令；进入目标地图时恢复该地图的相机、图层状态、工具、当前工作区和素材选择，并清除临时棋子选择/拖拽预览。
- 最新验证：Unity `6000.3.22f1`、许可证握手通过；EditMode `93/93`、PlayMode `15/15`，0 失败、0 跳过。本机 XML 为 `TestResults_EditMode_20260830_214327.xml` 和 `TestResults_PlayMode_20260830_214327.xml`；新增测试覆盖两张地图互不覆盖、旧状态读取、切换后相机恢复、保存后重新读取地图槽。
