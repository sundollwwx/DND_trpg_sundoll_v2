# M4 结果报告：项目棋子库与空间交互第一批

日期：2026-08-30
状态：**M4 核心棋子交互已完成，状态为 Ready with limitations**

## 本批已完成

- 新增可扩展的 `Asset / Definition / Instance` 纯数据模型。
- 资产使用现有 M2 内容寻址存储，重复二进制按 SHA-256 去重。
- 图片或缩略图文件缺失时保留资产记录和棋子实体，不静默删除。
- 新增 `Unplaced`、`OnBoard`、`InContainer`、`Attached` 四种互斥位置。
- 支持棋盘堆叠顺序、收入容器、附着、解除关系、旋转、翻面和显隐。
- 容器/附着关系提交前进行循环检测；越界位置、未知定义和未知目标会拒绝。
- M4 命令接入现有 Command Bus、Undo/Redo、版本化 Command Envelope 和 Journal 重放。
- Workbench 使用新的本地开发根目录 `SundollWorld_M4`，不改写既有 M1/M2/M3 开发样本。
- Workbench 增加“新增占位棋子”入口，缺少正式图片时使用可替换的占位色块显示。
- Workbench 棋子库面板支持按名称/分类/标签搜索、定义/实例列表、创建多个实例，以及将选中实例放置到选区、移动、旋转、翻面、显隐和解除关系。
- 增加 Unity 运行时图片导入边界：尺寸/字节大小校验、PNG 缩略图生成、内容寻址存储和坏图片拒绝；上层 Workbench 通过文件选择器接缝提供路径。
- 增加 macOS 原生图片文件选择器：Workbench 的“选择图片文件”按钮调用系统 Open 面板，取消/超时/平台不支持均回退为可读状态；非 macOS 继续使用显式路径输入。
- 左侧工具/棋子库和右侧 Inspector 改为独立纵向滚动栏，低高度桌面窗口仍可触达图片选择和棋子关系操作入口。
- Workbench 棋盘现已支持点击选择、Shift/Ctrl/Cmd 多选、框选、多选拖动 Ghost 预览，以及旋转、翻面、显隐和删除快捷操作；一次拖动或批量操作只提交一条权威命令。
- 新增 `M4.MovePieces`、`M4.SetPiecePresentations`、`M4.DeletePieces` 三种版本化批量命令，均接入 Undo/Redo、Command Envelope 与 Journal 重放；越界拖动和删除仍被未选中子项引用的目标会整体拒绝，避免半完成或数据丢失。
- 新项目可通过顶部“发布并创建棋盘”显式将地图草稿发布为主持棋盘；不完整（无稳定 ID）的旧棋盘不会再被当作可放置棋子的有效棋盘。
- Inspector 的收纳/附着目标改为可选列表，不再要求手工输入实例 ID。
