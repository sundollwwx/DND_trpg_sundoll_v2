# SundollWorld Workbench UX 重构计划

> 状态：UX1–UX6 已完成，UX7 进行中
> 目标：将当前集中式功能原型重构为清晰、舒适、可长期扩展的地图制作、棋子库与主控台工作空间。

## 1. 当前问题

- 当前“地图 / 棋子 / 层级 / 主持”只切换左侧窄栏，中央地图、顶部主持按钮和右侧操作始终混在一起，用户无法形成稳定的工作区心智模型。
- `M3WorkbenchRoot` 同时承担布局、项目、地图、棋子、主持、Inspector 和状态刷新，继续扩张会提高修改成本和回归风险。
- 地图视口缺少明确的地图外框、越界区域和边缘反馈，制作地图时不容易判断地图实际尺寸。
- 地图工具、图层和素材挤在纵向滚动栏中；文字按钮密度高，层级、间距和主次关系不清晰。
- 右侧 Inspector 以 Revision、Cell 数量和技术 ID 为主，没有围绕当前棋子展示可理解、可操作的状态。

## 2. 产品结构

项目中心保留为项目生命周期弹窗。主 Workbench 提供三个一级工作空间，通过左上角紧凑按钮组切换整个页面：

1. **地图制作**：地图、图层、素材与地图对象编辑。
2. **棋子库**：定义、图片、分类、标签、导入和实例创建。
3. **主控台**：主持地图、玩家预览、棋子调度、迷雾、标注与互动。

切换按钮必须带图标、中文名称、Tooltip、选中状态和键盘焦点，不能只依赖颜色表达状态。项目中心不作为常驻第四页，层级视图归入地图制作和主控台的上下文面板。

## 3. 统一 Workbench 外壳

```text
┌ 项目名称 │ [地图制作] [棋子库] [主控台] │ 撤销/重做 │ 保存 ┐
├────────┬──────────────────────────┬─────────────┤
│工作区导航│     当前工作区的主要内容      │ 情境 Inspector │
│  48px   │                          │   320px      │
├────────┴──────────────────────────┴─────────────┤
│ 坐标、缩放、选择数量、保存状态、错误提示             │
└─────────────────────────────────────────────────┘
```

- 外壳采用深蓝黑低饱和色；地图画布使用暖灰、羊皮纸和自然土色，避免整个窗口都是同一片深色。
- 常驻底栏压缩到约 28–32px；历史、错误和诊断使用可展开抽屉。
- 正文对比度至少 4.5:1，常用点击区域不小于 32px，焦点、Hover、选中和禁用状态必须可区分。
- 正式布局进入 UXML，样式集中在 USS/TSS；只允许动态位置、显隐和尺寸保留少量内联样式。

## 4. 地图制作工作区

### 4.1 布局

- 顶部情境工具栏：选择、画笔、橡皮、直线、矩形、填充、笔刷大小、网格、吸附、撤销和重做。
- 左侧上下文页签：`地图`、`图层`、`素材`。
- 中央为尽可能大的 Tilemap 画布。
- 右侧根据选择显示棋子、地图对象、格子选区或地图属性。
- 底部显示格坐标、当前图层、缩放、选择数量和保存状态。

### 4.2 明确地图边界

地图边界是功能门槛，不是装饰效果：

- 地图有效区域必须有持续可见的 2–3px 外框，缩放后仍保持清晰。
- 地图外区域使用更暗、低对比、不可编辑的背景；地图内外必须一眼可分。
- 最外圈格线、四角和原点提供细微强调；可选显示顶部/左侧坐标刻度。
- 笔刷或粘贴 Ghost 到达边界时显示警告色；任何越界批量操作继续整体拒绝，不能部分落地。
- 平移允许在地图外保留有限观察余量，但提供“适应地图”按钮并阻止地图永久迷失在视口外。
- 新建或调整地图尺寸时在画布上实时预览边界，确认后才提交命令。
- 玩家预览使用相同地图边界，但隐藏编辑网格、工具 Ghost 和主持专用反馈。

### 4.3 地图编辑体验

- 素材使用缩略图网格，支持分类、搜索、最近使用与收藏；不再依赖大量纯文字按钮。
- 图层行使用眼睛、锁、拖动排序和选中强调，隐藏与锁定不能只显示“显/隐、锁/开”文字。
- 增加清晰但不过亮的网格、笔刷预览、选区轮廓、粘贴 Ghost、锁定反馈和越界反馈。
- 工具切换、边界、图层和素材选择保持每张地图独立的 Workspace State。

## 5. 棋子库工作区

- 左侧提供搜索、分类、标签、来源、缺失资源和重复内容筛选。
- 中央使用虚拟化缩略图网格，不显示地图编辑工具。
- 右侧显示棋子定义：缩略图、名称、分类、标签、素材来源、引用次数、缺失状态和重新绑定操作。
- 导入、创建定义和“创建实例并放到地图”是明确分开的动作。
- 用户原图继续保存，列表优先加载显示代理并服从纹理缓存预算。

## 6. 主控台工作区

- 左侧为主持地图列表、场景层级和常用主持工具。
- 中央提供主持地图与玩家预览切换；玩家预览必须来自 Audience Projection。
- 右侧显示当前棋子、迷雾、标注或交互对象状态。
- 迷雾揭示/隐藏、动态标注和对象动作使用情境工具栏，不与地图地块笔刷混在同一工具列表。
- 多地图切换前继续保存当前草稿，切换后恢复各地图视口与主持状态。

## 7. 右侧情境 Inspector

### 7.1 单选棋子

- 缩略图、显示名称、定义和标签。
- 所在地图/棋盘、坐标、堆叠顺序。
- 未放置、棋盘中、容器中或附着状态。
- 旋转、翻面、主持可见性、容器目标、附着目标和槽位。
- 旋转、显隐、移出容器、解除附着和删除等操作。
- 稳定 ID 放入折叠的诊断区，不作为主信息。

### 7.2 多选棋子

- 显示选择数量和共有/混合状态。
- 提供批量移动、旋转、翻面、显隐和删除。
- 不展示只属于某一个实例的关系字段。

### 7.3 无棋子选择

- 选中地图对象时显示对象类型、坐标、旋转和动作状态。
- 选中格子区域时显示范围、尺寸、涉及图层和批量操作。
- 完全无选择时显示地图摘要；Revision 等开发字段进入诊断抽屉。

### 7.4 规则无关状态扩展

第一阶段只展示现有位置、旋转、翻面、显隐、堆叠、容器和附着状态，不升级 World Schema。生命、护甲、状态效果和备注作为第二阶段的规则无关扩展：资源条、状态列表、自定义字段、主持备注和玩家可见性；提供常用模板但不把 D&D 字段写死在 Core。

## 8. 代码拆分

- `M3WorkbenchRoot` 缩减为组合根，只创建 `WorkbenchSession`、外壳、工作区控制器和生命周期绑定。
- 新增 `WorkbenchShellController`、`WorkspaceNavigationController`、`MapEditorWorkspaceController`、`PieceLibraryWorkspaceController`、`HostConsoleWorkspaceController`、`PieceInspectorController` 与 `SelectionContext`。
- 复用现有 `IWorkbenchPanelController.Bind/Refresh/Dispose` 和 `WorkbenchSession`。
- 所有正式修改继续通过 Facade / Command Bus，保持 Undo、Journal、异步保存与 Canonical Hash。
- UI 刷新以 Selection、World Revision 和 SaveStatus 事件驱动，隐藏工作区不得继续进行昂贵的列表刷新。

## 9. 执行批次

1. **UX1 外壳与导航**：三个完整工作区、小型切换按钮、状态栏和 UXML/USS 基线。
2. **UX2 地图边界与工具布局**：边界投影、地图内外视觉、工具栏、图层与素材面板。
3. **UX3 情境 Inspector**：棋子单选/多选、地图对象、选区与无选择状态。
4. **UX4 棋子库页面**：独立筛选、缩略图网格、定义详情与导入流程。
5. **UX5 主控台页面**：地图列表、主持/玩家预览、迷雾、标注和交互工具。
6. **UX6 规则无关棋子状态**：经独立 Schema 评审后增加资源条、状态效果和备注。
7. **UX7 视觉与性能收尾**：键盘焦点、中文布局、窗口缩放、空闲分配、截图与 Player 验收。

## 10. 验收条件

- 三个工作区切换会替换整个主内容与情境工具，不只是切换左侧栏。
- 进入地图制作后，无需阅读尺寸文字即可识别地图边界；越界位置不可编辑并有明确预览反馈。
- 单击棋子后，右侧在一帧内显示对应实例状态；多选时显示批量状态。
- 棋子库页面不出现地图/主持工具；主控台不出现地图素材编辑按钮。
- 1440×900 与 2560×1440 均无关键控件裁切；窗口缩小时面板可滚动或折叠。
- 常用操作支持鼠标和现有快捷键，焦点状态可见，状态不只靠颜色传达。
- 现有 EditMode/PlayMode 不回退，并新增工作区隔离、地图边界、Inspector 状态和 View 重建测试。
- UI 重构不改变 Save v1/schema 2；只有 UX6 经单独评审后才允许升级世界 Schema。
