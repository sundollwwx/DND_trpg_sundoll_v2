# M4 结果报告：项目棋子库与空间交互第一批

日期：2026-08-25
状态：**M4 第一批已实现，整体 M4 仍为 Partial**

## 本批已完成

- 新增可扩展的 `Asset / Definition / Instance` 纯数据模型。
- 资产使用现有 M2 内容寻址存储，重复二进制按 SHA-256 去重。
- 图片或缩略图文件缺失时保留资产记录和棋子实体，不静默删除。
- 新增 `Unplaced`、`OnBoard`、`InContainer`、`Attached` 四种互斥位置。
- 支持棋盘堆叠顺序、收入容器、附着、解除关系、旋转、翻面和显隐。
- 容器/附着关系提交前进行循环检测；越界位置、未知定义和未知目标会拒绝。
- M4 命令接入现有 Command Bus、Undo/Redo、版本化 Command Envelope 和 Journal 重放。
- Workbench 使用新的本地开发根目录 `SundollWorld_M4`，不改写既有 M1/M2/M3 开发样本。
- Workbench 增加“新增占位棋子”入口，缺少正式图片时使用可替换的占位色块显示。
- Workbench 棋子库面板支持按名称/分类/标签搜索、定义/实例列表、创建多个实例，以及将选中实例放置到选区、移动、旋转、翻面、显隐和解除关系。
