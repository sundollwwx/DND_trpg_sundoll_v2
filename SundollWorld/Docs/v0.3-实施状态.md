## 当前执行顺序

1. 已完成 Journal 状态缓存、损坏尾部续写、HEAD 缺失/损坏扫描、generation 冲突和旧 HEAD 保留自动化。
2. 已完成地图运行时索引、版本化 `WorldChangeSet`、CommandEnvelope、AcceptedOperationBatch 和 Delta Undo/Redo。
3. 已接入 Journal 命令 Payload 重放，并保持旧开发存档读取路径。
4. 已建立单写入异步保存队列和明确的保存状态；运行时手动保存和事务阈值自动保存均进入队列。
5. 已为 `M2ProjectStore` 增加 OS 级 `.save.lock`、锁超时和 expected generation 的锁内复查；故障注入可验证 revision 写入失败、权限失败时 staging 清理和旧 HEAD 保留。
6. 已用正交 Camera、Tilemap 与 UI Toolkit 建立正式 Workbench，并补齐 Input System 编辑/视口、选择、剪贴板、旋转、图层排序及门/箱对象。
7. 已完成 M4 棋子库纯数据、四种位置关系、关系循环校验、资产去重、版本化命令/Journal 接入、占位/真实纹理投影、路径导入、堆叠/收纳/附着操作 UI；原生文件选择器和正式图片管理视觉体验仍待补齐。
8. 已完成 M5 多地图槽位、迷雾、动态标注和交互状态的权威命令切片；已完成 M6A 规则决策证明、M6B Loopback Snapshot/Delta Tail/Audience Projection；已完成 M7 Save v1/schema 2 冻结、迁移注册表、Frozen Save、Golden Hash、对象池、纹理缓存和性能采样入口。

Windows IL2CPP、Windows 原子写盘、跨平台互开和双平台强制退出矩阵是发布阻塞项，最迟必须在 M7 Beta 候选前通过。
