日期：2026-08-24

## 当前结论

M0 的数据与存档方向已在不依赖 Unity Scene 的前提下通过独立验证；Unity 6.3 LTS `6000.3.22f1` 的一次性 Spike 工程也已完成首次导入、脚本编译、运行时探针和构建验证。正式产品工程仍不在本 Spike 中初始化。

## 已知环境限制

- 本机已安装 Unity Editor 6.3 LTS `6000.3.22f1`，并包含 macOS IL2CPP 与 Windows Mono 支持。
- 当前没有可识别的 Unity MCP bridge。
- 当前没有 Windows 机器/CI，也未安装 Windows IL2CPP 模块；Windows IL2CPP 不能在本轮声称已通过。
- 桌面已解锁并完成一次真实 Unity Editor 复核：`M0Smoke` 场景成功加载，进入/退出 Play Mode 正常，Game 视图显示相机画面，Console 未出现红色错误。
- 当前 Spike 的正式产品 UI 尚未建立，但已加入一次性 Editor-only 可见工作台探针。已手动验证中文 UI、Inspector `PropertyField` 绑定、名称/Revision 修改、绑定值回读，以及从 Unity Project 面板选择 `M0DropProbe.png` 到 `Texture2D ObjectField`。Finder 到 Unity 的真实跨窗口鼠标拖放已尝试但未触发面板状态变化，因此仍只计无界面 payload adapter 通过。
