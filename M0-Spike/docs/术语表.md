# M0 术语表

| 术语 | M0 约定 |
| --- | --- |
| ProjectDocument | 项目权威数据的根文档，包含目录、地图草稿、地图发布版本、棋子定义和场景。 |
| MapDocument | 可编辑地图草稿；绘制会改变它，但不会自动产生不可变内容版本。 |
| MapContentVersion | 用户显式发布后产生的不可变地图内容；Board 固定引用它。 |
| ScenarioDocument | 主控台场景文档，包含 Board、PieceInstance、对象状态、迷雾和标注。 |
| BoardInstance | 对一个已发布 MapContentVersion 的场景实例。 |
| PieceDefinition | 项目棋子库中的定义，不等同于棋盘上的棋子。 |
| PieceInstance | 场景中的棋子实例；其空间位置由唯一 `PieceLocation` 表达。 |
| PieceLocation | `Unplaced`、`OnBoard`、`InContainer`、`Attached` 四种互斥空间状态。 |
| WorldRevision | 每次成功权威事务递增的因果修订号。 |
| EntityVersion | 单个实体用于并发前置条件的版本号。 |
| SaveRevision | 一次完整、可验证、不可变的持久化快照。 |
| HEAD | 指向当前活动 SaveRevision 的极小原子提交文件。 |
| JournalStream | 恢复日志的分支/纪元；回退历史 Revision 后必须开启新 Stream。 |
| OperationSequence | 某个 JournalStream 内连续递增的 AcceptedOperation 序号。 |
| DomainCommand | 会改变权威状态、进入存档并可进入未来网络的语义命令。 |
| WorkspaceAction | 面板宽度、搜索词、本机相机等不进入权威项目状态的动作。 |
| PreviewAction | 拖拽 Ghost、画笔预览、框选矩形等临时动作。 |
| LocalAuthority | 单机阶段也使用的命令验证、幂等、版本和事务提交边界。 |
| Canonical State Hash | 排除时间戳、本机偏好和显示摘要后，对权威状态规范化计算的 Hash。 |
| Blob Store | 按二进制 SHA-256 保存用户图片的项目内资源目录。 |
| LKG | last-known-good，最近一次已验证可恢复的完整 Revision。 |
