# M0 范围冻结 v0

日期：2026-08-23

## 本阶段包含

- 锁定 Unity LTS 候选、目标平台、渲染/UI/输入/测试方向和构建后端。
- 建立可丢弃的独立数据层 Spike。
- 证明规范化 Hash、命令原子提交、幂等、Undo/Redo、纯数据重建。
- 证明中文路径、内容寻址资产、不可变 Revision、原子 HEAD 和损坏 Journal 尾部处理。
- 给出下一次真实 Unity Editor Spike 的验证清单。

## 本阶段不包含

- 不创建正式 Unity 工程、`Assets/Sundoll/` 或产品 Scene。
- 不安装 Unity Editor、Unity 包、Unity MCP 或第三方网络框架。
- 不读取、复制或转换历史网页项目的代码、数据、存档、地图、图片或音乐。
- 不实现产品 UI、地图编辑器、棋子库、主控台或正式存档服务。
- 不冻结 pre-v1 存档兼容承诺，不做真实 Windows 构建。
- 不实现 D&D/其他具体规则、正式网络、账号、Relay、云存档或模组系统。

## M0 退出规则

独立验证全部通过只能证明数据层方向可继续；正式进入 M1 前仍必须补做 Unity Editor 实测：UI Toolkit 拖放/Inspector、Tilemap 对照、运行时图片、IL2CPP macOS/Windows Smoke Build 和双平台保存故障注入。若其中任一项不通过，回到 ADR 或技术方案修订，不初始化正式工程。
