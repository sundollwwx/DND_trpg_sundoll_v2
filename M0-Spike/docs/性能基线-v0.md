# M0 性能基线 v0

本文件区分“独立数据层实测”和“Unity 目标门槛”。前者用于验证数据结构与算法方向，不能替代真实 Editor/Player 基准。

## 目标门槛（来自工作计划，待 Unity 环境校准）

| 项目 | 首轮目标 |
| --- | ---: |
| 合成地图 | 256×256 方格，最多 10 个内容/运行层 |
| 可见棋子 | 1000 个，2560×1440 视口平移缩放 60 FPS |
| 数据压力 | 10000 个实例 |
| 普通交互 | 主线程 p95 < 50 ms |
| Snapshot 捕获 | 主线程停顿 p95 < 16 ms，单次最大目标 < 50 ms |
| 后台 Save Revision | 基准项目 p95 < 2 秒，主线程不等待磁盘 flush |
| 10000 个操作恢复 | < 5 秒 |
| 图片导入 | 有单图像素、解码内存和总纹理预算 |

## 独立数据层测量

运行 `python3 M0-Spike/scripts/verify_m0.py` 后，脚本会把当前机器的 Hash、规范化序列化、10000 操作重放和 256×256 合成地图测量写入 `results/m0-verification.json`。测量对象是 Python 标准库实现，结果只用于相对趋势和格式可行性判断。
