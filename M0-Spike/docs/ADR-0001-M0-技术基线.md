# ADR-0001：M0 技术基线

- 状态：M0 正式接受，保留 Windows IL2CPP/原子写盘与 Finder 真实拖放限制
- 日期：2026-08-25
- 范围：一次性 Spike 与后续正式工程的初始技术方向

## 决策

1. 正式产品使用 Unity Runtime 桌面应用，目标平台为 Windows 与 macOS，首版为中文 2D 顶视方格工作台。
2. Unity 基线锁定为 Unity 6.3 LTS `6000.3.22f1`。本机 Apple Silicon 对应短修订为 `1c726e1fb402`；正式工程与后续批处理验证固定使用该版本。
3. 渲染方向采用 URP 2D Renderer；工作台采用 UI Toolkit；输入采用 Input System；Unity Test Framework 作为测试入口。
4. 生产构建以 IL2CPP 为目标；开发期可用 Mono 做快速迭代，但不得替代 IL2CPP Smoke Build。
5. Addressables 只管理随构建发布的内置内容；用户图片进入项目自己的内容寻址 blob store，不写入 Addressables，也不以 base64 写入 JSON。
6. Core/Domain 保持纯 C#，不引用 UnityEngine；Scene、GameObject、Transform、Tilemap 和 MonoBehaviour 只做投影与输入。
7. 地图渲染先以 Tilemap 作为 M0 基线，同时保留可见区自绘网格作为对照；只有真实基准证明 Tilemap 不达标时才切换，不预先引入 DOTS 或复杂 Chunk 存档。
8. 存档采用完整不可变 JSON Revision + 内容寻址二进制资产；`HEAD.json` 最后原子替换；Recovery Journal 只作为有限崩溃恢复辅助手段。
9. 单机从第一天经过 `LocalAuthority`、版本化 Command 和 `NoRules/AllowAll`；不安装具体网络框架，不把未来网络类型带入 Domain/Save DTO。
10. M0 Spike 使用全新合成内容，验证失败可整体丢弃；该门槛已经完成，正式产品工程 `SundollWorld` 已建立。

## 证据

- 一次性 M0 Spike 已完成独立数据验证、Unity Editor 验证和 macOS IL2CPP 验证；Windows Mono 构建已经留证，Windows IL2CPP 与真实 Windows 原子写盘尚未关闭。
- 正式工程已位于 `SundollWorld/`，包含 `Assets/`、`Packages/manifest.json` 和 `ProjectSettings/ProjectVersion.txt`；该工程是 M0 决策的后续实施结果，不属于一次性 Spike。
- Unity Hub 本地 GraphQL 缓存记录了 `Unity 6.3 LTS` 的 LTS 查询及 `6000.3.22f1`、发布日期 `2026-08-13`、macOS ARM64 下载短修订 `1c726e1fb402`。
- Unity 官方入口：[Unity 6 releases](https://unity.com/releases/unity-6)。本机为 Apple Silicon macOS，Unity Editor `6000.3.22f1` 与构建支持已用于后续验证；当前未接入 Unity MCP。

## 代价与后续复核

- Finder 到 Unity 的真实跨窗口拖放尚未形成可复核证据，因此继续登记为限制；这不阻止 macOS 上推进后续里程碑。
- Tilemap 与自绘网格的选择不能用通用经验替代本产品地图规模基准。
- macOS IL2CPP 已完成；Windows IL2CPP、Windows 原子写盘和 Windows Smoke 仍需要真实 Windows 环境。
- `6000.3.22f1` 是当前 M0 基线，不是对外发布版本承诺；安装时如 Unity Hub 的 LTS 结果变化，应更新 ADR 并重新记录短修订。
