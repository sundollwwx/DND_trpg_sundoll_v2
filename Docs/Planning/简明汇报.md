## 一、方向已经改变

新路线是 **Unity 原生从零开发**，不是旧网页项目迁移。

历史项目只提供工作流思想：地图制作、棋子管理、主控台主持、通用关系、本地恢复和未来玩家端。新工程不会读取或复制旧代码、地图、棋子、存档、图片、音乐，也不会开发旧格式导入器或做兼容验收。

## 二、首版产品范围

首版是一款 Windows/macOS 的中文 2D 方格桌面应用，包含四个工作区：

1. 项目中心：新建、打开、保存、恢复与便携包。
2. 地图制作器：图层、常用绘制工具、框选、复制粘贴、Undo/Redo、交互物和地图发布。
3. 项目棋子库：定义、图片、缩略图、分类、标签、搜索和缺图占位。
4. 主控台：多地图、棋子操作、迷雾、标注、对象状态与通用互动。

棋子首批支持移动、旋转、翻面、显隐、堆叠、收纳、附着与解除附着。暂不加入具体玩法规则。

## 三、核心架构决定

- 纯 C# 世界状态是唯一真相，Unity Scene 和 Transform 只做显示。
- 正式修改统一走命令管线，Undo、存档恢复、未来规则和联机共用一条路径。
- 地图分为可编辑草稿、显式发布的不可变版本和主控台实例。
- 棋子分为项目库定义、棋盘实例和独立视觉资产。
- 单机也使用 `LocalAuthority`；未来采用主机/服务器权威，不同步 GameObject。

## 四、存档方案

日常项目采用 `.sundollproj` 目录：完整不可变 Save Revision、原子 `HEAD.json`、自动保存、last-known-good 和分段崩溃恢复日志。用户图片按 Hash 去重，缺图不删除实体。

便携分享采用 `.sundollpkg`，只打包一个已验证 Revision 及其引用素材。Pre-v1 开发档不承诺兼容；完成真实工作流和扩展证明后再冻结 v1。

## 五、规则与联机边界

- 当前只提供 `NoRules/AllowAll`，Alpha 后期用独立微型测试规则证明规则可插拔。
- Alpha 后期只做进程内 Loopback，验证幂等、冲突、断线追赶和 Audience Projection。
- 真实规则、网络框架、房间、账号、Relay、云存档和专用服务器另行立项。

## 六、阶段与工期

路线为：技术验证 → 最小纵向闭环 → 新格式存档 → 地图制作器 → 棋子库与交互 → 主控台 → 规则/Loopback 接缝证明 → v1 与 Beta 加固。

- 内部功能闭环：约 16–17 人周，不对外承诺 pre-v1 存档兼容。
- 规则与 Loopback 架构验证完成：约 19–20 人周；含风险缓冲约 23–24 人周。
- 冻结 v1 后的可对外测试 Beta：约 22–24 人周；含风险缓冲约 27–29 人周。

估算按一名熟悉 Unity/C# 的全职开发者计算，不含真实联网、具体规则、专业美术和商店发布合规。

## 2026-08-31 UX5 进展

主控台第一批视觉整理已完成：主持地图、当前主持状态、迷雾笔刷、动态标注和交互对象现在分别位于独立区块，主控台与地图制作/棋子库继续是互斥工作区；同时移除了 Unity 6 不支持的 USS 属性。
